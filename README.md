# 🌌 Aurora Diary

> **Midnight Aurora** 테마 기반의 프리미엄 다크 모드 TUI(Terminal User Interface) 및 CLI 일기장 시스템.  
> 리눅스 전문가를 위해 고안되었으며, 프라이버시가 완벽히 보장되는 로컬 스토리지와 마크다운 저작 환경을 결합했습니다.

---

## ✨ 핵심 기능

1. **Midnight Aurora 프리미엄 TUI**: 
   - 깊은 밤의 오로라 광원을 본뜬 청록(Cyan), 보라(Purple), 핫핑크(Pink) 네온 그라데이션이 적용되어 시각적으로 매우 수려한 터미널 인터페이스를 선사합니다.
2. **대화형 캘린더 위젯**: 
   - 달력 내에서 날짜별 일기 작성 여부와 기분(감정 이모지)을 한눈에 확인할 수 있습니다.
3. **네이티브 Vim/Nano 연동**: 
   - 본문 작성 시 제한적인 터미널 인풋창을 벗어나, 사용자가 설정한 시스템 에디터(`$EDITOR` 또는 `vim`/`nano`)를 안전한 샌드박스 서스펜드 방식으로 자동 실행합니다. 마크다운 에디팅을 완벽 지원합니다.
4. **이미지 아스키 아트 프리뷰 및 외부 연동**: 
   - 사진 경로를 추가하면 터미널 격자 비율에 정교하게 맞춘 **그레이스케일 아스키 아트**로 실시간 미리보기를 제공하며, `[P]` 키를 눌러 `xdg-open`으로 외부 정밀 이미지 뷰어를 띄울 수 있습니다.
5. **감정 상태 통계 추적**: 
   - 최근 30일 동안의 기분 분포를 오로라 그라데이션이 적용된 가로형 아스키 차트로 시각화합니다.
6. **강력한 CLI 모드 지원 (터미널 쉘 파이프라인 친화)**: 
   - TUI를 켜지 않고도 CLI 환경에서 즉각 최근 리스트 조회, 다중 조건 키워드 검색, 데이터 백업/가져오기 처리가 가능합니다.

---

## 🛠️ 설치 및 설정 방법

의존성 격리와 실행의 간편함을 위해 원클릭 자동화 스크립트를 제공합니다.

### 1. 자동 설치 실행
프로젝트 디렉토리 내에서 아래 명령을 실행합니다.
```bash
chmod +x install.sh
./install.sh
```
*스크립트는 파이썬 가상환경(`.venv`) 생성, 라이브러리(`textual`, `rich`, `pillow`) 설치, 그리고 사용자가 어디서나 실행할 수 있도록 `~/.local/bin/aurora-diary`에 래퍼 스크립트를 안전하게 자동 등록합니다.*

### 2. 환경 변수 확인 (선택)
설치 후 `aurora-diary` 명령어를 찾을 수 없다는 오류가 발생할 경우, `~/.bashrc` 또는 `~/.zshrc` 파일 하단에 아래 환경 변수 경로를 등록해 주세요.
```bash
export PATH="$HOME/.local/bin:$PATH"
```

## ⌨️ TUI 모드 단축키 (핫키) 가이드

TUI 일기장 내부에서 사용할 수 있는 키 매핑 테이블입니다:

| 단축키 (Key) | 기능 및 역할 |
| :--- | :--- |
| `N` | **신규 일기 작성**: 선택한 날짜에 새로운 일기 작성창(모달)을 띄웁니다. |
| `E` | **일기 편집**: 이미 작성된 일기가 있다면 제목, 기분, 태그 및 본문을 수정합니다. |
| `D` | **일기 삭제**: 현재 선택된 날짜의 일기를 안전하게 즉시 삭제합니다. |
| `F` | **통합 검색**: 실시간 키워드 필터링 모달을 띄워 일기 목록에서 원하는 날짜로 빠르게 이동합니다. |
| `◀` (Left Arrow) | 캘린더를 **이전 달**로 변경합니다. |
| `▶` (Right Arrow) | 캘린더를 **다음 달**로 변경합니다. |
| `P` | 일기에 첨부된 이미지가 존재할 경우, 외부 이미지 뷰어(`xdg-open`)를 통해 실시간으로 띄웁니다. |
| `Q` | Aurora Diary를 안전하게 **종료**합니다. |

## 💻 CLI 모드 명령어 가이드

바쁜 작업 중 터미널 쉘 내에서 일기 이력을 조회하거나 정합성 체크, 백업 등을 수행할 때 사용합니다.

### 1. 일기 목록 간략 조회
최근 작성된 일기 10개를 Midnight Aurora 테이블 레이아웃으로 즉각 출력합니다.
```bash
aurora-diary -l [출력개수]
# 예: 최근 5개만 조회
aurora-diary -l 5
```

### 2. 키워드 통합 검색
제목과 본문, 태그에서 특정 검색어를 고속 검색하여 결과를 출력합니다.
```bash
aurora-diary -s "검색키워드"
# 예:
aurora-diary -s "개발"
```

### 3. 데이터 안전 백업 (Export)
현재 작성된 전체 일기장 데이터베이스(JSON 포맷)를 지정한 안전한 외부 백업 파일로 내보냅니다.
```bash
aurora-diary -e ~/backups/my_diary_backup.json
```

### 4. 데이터 안전 복원 (Import)
기존에 백업해 두었던 JSON 파일을 읽어 데이터베이스를 완벽하게 복구합니다.
```bash
aurora-diary -i ~/backups/my_diary_backup.json
```
*(기존 데이터가 덮어씌워지므로 백업 가동 전 확인 프롬프트가 한 번 출력됩니다.)*

## 🔒 데이터 보안 및 프라이버시

모든 데이터는 네트워크 외부로 송출되지 않고 오직 사용자 로컬 시스템 내에 암호화/비압축 텍스트 형태로 온전히 보존됩니다.
- **기본 데이터 저장 경로**: `~/.config/aurora-diary/diary.json`
- 해당 파일을 정기적으로 백업해 두시면 기기 변경 시에도 완벽하게 복구할 수 있습니다.
